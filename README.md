## ✨ Özellikler

- Ürünleri kategorilere göre listeliyorum
- Ürün ekleyip silebiliyorum, düzenleyebiliyorum
- Arama kutusu ve kategori filtresi var
- Fiyata ve isme göre sıralama yapılabiliyor
- Her ürünün detay sayfası var
- React Router ile sayfa geçişleri
- Context API ile global state yönetimi

## 🛠 Teknolojiler

- React
- Context API — global state için
- React Router v6 — sayfa yönlendirme için
- Vite — geliştirme ortamı
